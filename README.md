# Skrewit Website

Hardware & construction supplies, delivered in minutes.

## Run locally
```
npm install
npm run dev
```

## Deploy (Vercel — recommended)
1. Push this folder to a GitHub repo.
2. Go to vercel.com → Add New Project → import the repo.
3. Framework preset: Vite (auto-detected). Click Deploy.
4. Add custom domain (skrewit.in / skrewit.com) in Vercel → Settings → Domains.

Every git push = automatic redeploy.
